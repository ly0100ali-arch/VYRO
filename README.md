# VYRO — تواصل بطريقتك

واجهة عربية RTL لتطبيق تواصل اجتماعي، بتصميم متجاوب يعمل على الهاتف والكمبيوتر.

## الموجود حالياً
- موجز منشورات وإنشاء منشور جديد.
- إعجاب بالمنشورات والتعليق عليها ومشاركتها.
- بحث داخل المنشورات.
- ملف شخصي قابل للتعديل.
- صفحات تنقل للرئيسية والاستكشاف والإشعارات والملف الشخصي.
- تصميم قابل للتثبيت كتطبيق ويب PWA مع ملف manifest وأيقونة.
- تخزين تجريبي محلي على الجهاز باستخدام localStorage، ودعم أساسي للعمل دون اتصال عبر Service Worker.

## تجربة التطبيق
افتح رابط GitHub Pages بعد تفعيله للمستودع:
`https://ly0100ali-arch.github.io/VYRO/`

## تفعيل النشر التلقائي
1. افتح إعدادات المستودع ثم **Pages**.
2. في **Build and deployment** اختر **GitHub Actions** كمصدر.
3. سيقوم ملف workflow في `.github/workflows/pages.yml` بنشر الموقع عند تحديث الفرع `main`.

## ملاحظات مهمة
هذه نسخة واجهة أولية وليست شبكة اجتماعية مكتملة بعد. المنشورات والإعجابات والتعليقات والملف الشخصي محفوظة محلياً على نفس المتصفح والجهاز، ولا تتم مزامنتها بين المستخدمين. لا يوجد حالياً خادم أو قاعدة بيانات أو تسجيل دخول حقيقي أو رفع صور. القصص والإشعارات الحقيقية قيد التطوير.

## الخطوات التالية
- إنشاء Backend وقاعدة بيانات.
- تسجيل حسابات آمن وجلسات مستخدمين.
- رفع الصور والوسائط وتخزينها.
- متابعة المستخدمين والإشعارات الفعلية.
- تجهيز إصدار Android APK بعد اكتمال ربط الخدمات الخلفية.


## الحسابات وقاعدة البيانات
- تمت إضافة واجهة إنشاء الحساب وتسجيل الدخول واستعادة كلمة المرور عبر Supabase Auth.
- تمت إضافة مخطط SQL للملفات الشخصية والمنشورات والتعليقات والإعجابات والمتابعة والإشعارات مع سياسات RLS.
- يلزم إعداد مشروع Supabase وإضافة URL ومفتاح anon/publishable إلى `supabase-config.js` لتفعيل الحسابات. اتبع الخطوات في `SETUP.md`.
- حتى إكمال الربط، تظل المنشورات في الواجهة الحالية محلية على الجهاز؛ لا تدّعِ أن المزامنة السحابية أو الرسائل أو رفع الصور مفعلة بعد.
